# Product Completion Quickstart

1. Run `npm run planning:verify` and `npm run capabilities:verify`.
2. Run the narrow unit/API/rules tests for the active phase.
3. Run `npm run check` at every major boundary.
4. Run the canonical final commands from the remediation plan.
5. Record real evidence only; leave external-evidence tasks unchecked and name
   the missing approval, credential, participant, operator, or production proof.
